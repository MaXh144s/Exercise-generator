Estrutura esperada do JSON

O JSON deve ter um array questoes. Cada questão pode ter os campos abaixo (numero, enunciado e alternativas são os essenciais — o campo correta é opcional, só é usado se você marcar "Marcar alternativa correta"). O campo tabela também é opcional: um array de linhas, cada linha um array de células (ex.: [["Embalagem","250 gramas"],["Preço","R$ 2,70"]]), exibido como uma caixa com bordas logo abaixo do enunciado.

Fora do array questoes, o campo secao é opcional: define o texto do banner que aparece no topo da primeira coluna (ex.: "Exercícios ENEM", "Lista de Exercícios" ou qualquer outro título). Se omitido, o padrão é "Exercícios Propostos".
